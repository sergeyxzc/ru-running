# Приложение для определения нормативов по бегу

## Общее описание

Приложение для определения нормативов по бегу нужно для быстрого нахождения норматива.

## Параметры поиска

### Обязательные поля (без них таблица не отображается)

- **Пол**: dropdown: Мужчины | Женщины. При изменении сбрасываются и блокируются все дочерние селекторы: "Место", "Дистанция", "Хронометраж", "Размер круга".
- **Место**: Стадион | Шоссе. При изменении сбрасываются и блокируются: "Дистанция", "Хронометраж", "Размер круга".
- **Дистанция**: dropdown со всеми уникальными значениями дистанций. Блокируется, пока не выбраны "Пол" и "Место". **После выбора дистанции таблица начинает отображаться** со всеми доступными нормативами для этой дистанции.

### Необязательные фильтры (сужающие выборку)

- **Хронометраж**: dropdown: Все | ручной | авто. Блокируется, пока не выбрана "Дистанция". При выборе фильтрует таблицы по типу замера. По умолчанию "Все" — показываются оба типа.
- **Размер круга** (опционально): dropdown со всеми уникальными значениями "Круг" для выбранной дистанции. Блокируется, пока не выбран "Хронометраж". Если для выбранных параметров все записи имеют `"Круг": null`, dropdown остаётся неактивным, но таблицы отображаются. При выборе фильтрует таблицы по размеру круга.

### Результат

Приложение возвращает нормативы для бега по выбранным параметрам в виде таблицы с колонками:
- **Разряд**
- **Время**

Таблицы отображаются **сразу после выбора дистанции**. Хронометраж и Размер круга лишь сужают показанные таблицы.

## Технические требования

- Приложение написано на HTML/CSS/JavaScript с использованием Bootstrap 5
- Обязательно масштабирование под мобильные экраны (адаптивный дизайн)

## Структура данных

Данные вшиты в файл `data.js` в виде следующих констант:
- **womanStadiumData** — данные для женщин на стадионе
- **womanRoadData** — данные для женщин на шоссе
- **manStadiumData** — данные для мужчин на стадионе
- **manRoadData** — данные для мужчин на шоссе

JSON-файлы с данными (`woman-stadium.json`, `woman-road.json`, `man-stadium.json`, `man-road.json`) **запрещено удалять** — они должны сохраняться для возможности удобного редактирования и синхронизации с `data.js`.

## Дизайн

Приложение использует тёмную тему **Night Runner** с природными акцентами:

- **Фон**: тёмный бирюзовый/грифельный (`#0d4f4f`, `#1e2933`, `#25333d`)
- **Текст**: белый и светло-серый с высокой контрастностью
- **Акцентные цвета** (CSS-переменные):
  - `--accent-gender`: зелёный (`#22c55e`)
  - `--accent-location`: янтарный (`#eab308`)
  - `--accent-distance`: фиолетовый (`#a855f7`)
  - `--accent-measurement`: голубой (`#0ea5e9`)
  - `--accent-circle`: бирюзовый (`#14b8a6`)

- **Шрифт**: Inter (подключается через Google Fonts)
- **Эффекты**:
  - Плавные переходы (`transition: all 0.25s ease`)
  - Тени для карточек и инпутов
  - Hover-эффекты на карточках (приподнимание)
  - Fade-in анимация при появлении результатов
  - Кастомный скроллбар в стиле приложения

- **Адаптивность**: полная поддержка мобильных устройств (viewport meta tag, медиа-запросы @media max-width: 768px)

## Архитектура приложения

### Последовательность зависимостей селекторов

```
Пол → Место → Дистанция → Хронометраж → Размер круга
       (обязательные)    (необязательные фильтры)
```

**Поведение при смене селектора:**

- При смене **родительского селектора** все дочерние селекторы:
  1. Сбрасываются в значение по умолчанию ("Все" или пустое значение)
  2. Блокируются (`disabled = true`)
  3. Разблокируются только после выбора родительского значения

- **Таблица отображается** сразу после выбора **Дистанции** (третьего обязательного поля)

- **Хронометраж** и **Размер круга** — необязательные фильтры:
  - По умолчанию установлено значение "Все"
  - При выборе сужают выборку отображаемых таблиц
  - Если "Круг" = null у всех записей, dropdown блокируется, но таблицы показываются

### Маппинг данных

В `app.js` используется объект `dataMapping` для связи ключей с данными:

```javascript
const dataMapping = {
    'woman-stadium': womanStadiumData,
    'man-stadium': manStadiumData
};
```

> **Примечание:** В текущей версии реализованы только данные для **стадиона**. Данные для шоссе (woman-road.json, man-road.json) должны быть добавлены в `data.js` и `dataMapping`.

### Структура данных

Каждая запись в массивах данных имеет вид:

```javascript
{
  "Дистанция": "3000м",
  "Хронометраж": "ручной" | "авто",
  "Круг": "200м" | "400м" | null,
  "Разряды": [
    {"Разряд": "КМС", "Время": "10:00,0"},
    {"Разряд": "I разряд", "Время": "10:55,0"},
    ...
  ]
}
```

## Запуск приложения

Откройте файл `src/index.html` в любом современном браузере
