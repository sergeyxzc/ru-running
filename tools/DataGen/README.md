# DataGen

Консольная утилита на .NET 10: собирает `src/data.js` из JSON-файлов каталога
`data-sets/` (стадионные нормативы ЕВСК). Без внешних NuGet-пакетов.

## Запуск

Из корня проекта:

```cmd
dotnet run --project tools/DataGen
```

По умолчанию читает `data-sets/*.json` и пишет `src/data.js`.
Пути можно переопределить:

```cmd
dotnet run --project tools/DataGen -- data-sets src/data.js
```

## Что делает

- Каждый файл `<имя>.json` превращается в `const <имяCamelCase>Data`
  (`woman-stadium.json` → `womanStadiumData`), порядок блоков: сначала
  женские данные, потом мужские — как в `dataMapping` в `src/app.js`.
- Формат вывода один в один как у исходного `data.js`: UTF-8 без BOM,
  CRLF, компактные строки разрядов.
- Перед записью валидирует данные: непустые поля, «Хронометраж» только
  `ручной`/`авто`, непустые «Разряды», без дубликатов ключа
  (Дистанция, Хронометраж, Круг). При ошибке выходной файл не трогается.
- Если содержимое не изменилось, файл не перезаписывается.

Коды возврата: `0` — успех, `1` — ошибка данных/ввода-вывода, `2` — неверные аргументы.
